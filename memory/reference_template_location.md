Template path: `~/.claude/templates/ts-react-project.md`

Usage: at new repo init, copy to `.claude/CLAUDE.md` in the project root and fill in `[Project Name]` and the Architecture section.

Last updated: 2026-06-10. Template contains React 19, Tailwind v4, Zustand, TanStack Query v5, Zod, pnpm. Verify library versions are still current at each project init — versions drift.
