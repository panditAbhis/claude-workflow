Maintain two separate GitHub accounts:
- Work account — for employer/company projects only
- Personal account — for personal projects only

**Why:** Mixing work and personal accounts creates audit trail problems and blurs professional boundaries.

**How to apply:** When starting work on a project, confirm which context it belongs to and use the matching GitHub account. When unclear, ask before assuming.
